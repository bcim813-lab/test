# Employee Laptop Monitoring System

## Project Overview
A Python-based Employee Laptop Monitoring System.

## Technology Stack
- Python
- FastAPI
- MongoDB
- Docker
- GitHub Actions
- Linux

## Project Goals
- Monitor employee laptop activities.
- Collect system information.
- Store monitoring data in MongoDB.
- Automate CI/CD using GitHub Actions.
- Deploy using Docker.

## Deployment
Local Linux Server using Docker Compose.
